# catan-energy — 発電所と汚染を足した陣取りボード

カタン基本セットに、カタン「New Energies（エネルギー版）」風のルールを足した試作。1台の画面を交代して3〜4人で遊ぶ（catan 本体とは別アプリで、拡張や5〜6人には対応していない）。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/catan-energy/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

カタン基本セットのルールで、3〜4人が1台の画面を回して交代で遊びます。席ごとに「人」か「CPU」（よわい・ふつう・つよい）を選べ、人が1人だけでも遊べます。
盤面をタップして開拓地・道・都市・発電所・盗賊の場所を選びます。下のボタンでサイコロ・建設・交易・発展カード・手番終わりを操作します。

## 足したルール

- **発電所**: 自分の開拓地・都市に1つずつ建てられる。
  - 化石燃料発電所（土1・鉄1、安い）
  - 再生可能発電所（木1・麦1・鉄2、高いが1点になる）。化石燃料の上に建て替えてよい（逆はできない）。
- **エネルギー**: 発電所のある町は、出目が当たるとふつうの資源にくわえてエネルギーも産む（開拓地1・都市2）。開始時に各自2持つ。
- 開拓地を建てるのにエネルギー1、都市を建てるのにエネルギー2が追加で要る（道・発展カードは不要）。
- **汚染**: 化石燃料発電所が産出するたびに、全体の汚染メーターが1上がる。5・10・15に達するたびに「災害」が起き、化石燃料発電所が一番多く隣接するタイル（同数ならランダム）が、以後産出しなくなる。
- 汚染が20に達すると即終了し、再生可能発電所が一番多い人の勝ち（同点なら点の多い人）。それ以外は、ふつうどおり10点で勝ち。
- 画面には汚染メーターと各自のエネルギー数を出し、発電所のある町には種類がわかる小さな印を付ける。
- CPU（よわい・ふつう・つよい）も発電所を建てる。エネルギーが足りなくて開拓地・都市を建てられないときは発電所を優先し、汚染が10以上たまっていれば再生可能を優先する。

## 省いた点

- 航海者版・都市と騎士・交易と略奪・サッカー熱・5〜6人拡張は、この試作では使わない（土台にした catan のコードには残っているが、設定画面からは選べない）。
- エネルギーを4対1交易の資源として使う仕組みは入れていない。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```
