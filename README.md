# catan-energy — 発電所と汚染の開拓ボードゲーム（試作）

町や都市に化石燃料か再生可能の発電所を建て、エネルギーと科学で島を広げる3〜4人用ボードゲームの試作。1台の画面を交代して遊ぶ。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/catan-energy/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方（30秒）

画面右上の「遊び方」ボタンからも同じ説明が見られます。

1. 席ごとに「人」か「CPU」（よわい・ふつう・つよい）を選ぶ。人が1人だけでも遊べる。
2. 手番は「イベント（ディスクを引く）」→「サイコロ」→「道・町・都市・発電所を建てる、交易する」の順。
3. 化石燃料発電所は安いが汚染（LF・GF）を増やし、ディスクを多く引くようになる。再生可能発電所は高いが汚染を下げる。
4. 自分の手番中に10点になれば勝ち。イベントディスクの袋が尽きたら、再生可能発電所が化石燃料発電所より多い人だけが勝てる（いなければ全員の負け）。

## 公式ルールとの違い

市販のボードゲームの公式ルールをもとに、画面で遊べるよう次の点だけ変えている。

| 点 | どうしたか | 理由 |
|---|---|---|
| 先手を決めるサイコロ | ランダムに1人選ぶ | 結果は同じで操作が1つ減る |
| 初回の固定配置 | 使わず、標準の配置（渦巻きの数字並べ）だけ | 図の座標を写す手間に見合わない |
| ルールに書かれていない場面 | ハザードの在庫切れは置かない／袋切れ終了で点も同じなら同時優勝／銀行の札が足りないときは基本カタンと同じ扱い | 公式ルールに記載が無いため、ここで決めた |
| 相手との交易の提案 | 手番の人が内容を出し、相手が受けるか断るだけ（逆提案はしない） | 1台の画面で回すため。出せる物（資源・科学・エネルギー）は公式どおり |

これ以外（準備・汚染・イベント・ハザード・建設・交易・発展カードなど）は公式ルールのまま実装している。

## 権利について

ルールは市販品の数値までなぞっているが、ゲームのルールそのものは著作権で守られない。ただし商標の都合で、商品名・拡張の固有名詞は画面やこの文書に書かない（種類の名前「発電所と汚染の開拓ボードゲーム」で呼ぶ）。絵・アイコンは自前のもの。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```

テスト: `node --test test.mjs`
